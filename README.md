# Library Management System

A C++ console-based library management system with book borrowing and user management features.

## Features

- 📚 Book inventory management (add, remove, search books)
- 👤 User registration and authentication
- 📖 Book borrowing and returning system
- 💾 Persistent data storage using text files
- 🔍 Search functionality for books
- 📊 View available and all books

## Technical Details

- **Language**: C++
- **IDE**: Visual Studio Code
- **Platform**: Windows 11
- **Compiler**: MinGW-w64 (GCC)
- **Data Storage**: Text files

## Project Structure
A comprehensive console-based Library Management System built with C++ featuring user authentication, book management, and borrowing functionality with persistent file storage.

## 🚀 Features

### Core Functionality
- **📖 Book Management**
  - Add new books to the library inventory
  - Remove existing books from the system
  - Search books by title or author (case-insensitive)
  - View all books and filter available books
  - Track book availability status

- **👤 User Management**
  - User registration with secure authentication
  - Login/Logout functionality
  - View user profile and borrowing history
  - Maximum 3 books per user limit

- **🔄 Borrowing System**
  - Borrow available books
  - Return borrowed books
  - Real-time availability updates
  - Borrowing history tracking

- **💾 Data Persistence**
  - Automatic saving to text files
  - Data survives program restarts
  - File-based storage system

### Technical Features
- Object-Oriented Programming (OOP) design
- Modular class structure
- File I/O operations
- Input validation and error handling
- Case-insensitive search functionality
- Console-based user interface
